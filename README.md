# Attraction Pattern Analyzer

## Overview
This project is a C++-based system that analyzes user attraction patterns by comparing what users think their type is with their actual behavioral tendencies.

## Features
- Type identification
- Ideal vs actual comparison
- Behavioral analysis
- Self-awareness scoring
- Pattern detection

## Project Idea
The system explores the gap between self-perception and real behavior by analyzing user preferences, past experiences, and scenario-based responses.
